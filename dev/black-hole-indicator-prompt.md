## 你的任务

实现一个音频驱动的黑洞特效：

- **静止时**：吸积盘上的光波缓慢地绕环流动并螺旋落入黑洞，顶部光晕像水面一样不规则地轻微呼吸，其余元素静止。
- **说话时**：一切加速——光流最快 2.5 倍，盘面波纹变深，黑洞与火环同步轻微胀大，底部大光晕开始快速颤动（不是胀缩）。
- **停止说话**：约 1 秒内平滑回到静息状态。
- **持续说话必须持续波动**（这是最容易做错的点，见"音频响应管线"）。
- 恒定帧成本：每帧 ≤ 9 次渐变绘制、≤ 12 次描边、≤ 84 段曲线重建、零对象分配。

## 逻辑画布与约定

- 逻辑画布 240 × 236，黑洞中心 C 位于 (120, 118)。整体可等比缩放。
- 本文所有坐标以 C 为原点、**y 轴向上**为正（如你的平台 y 向下，翻转裁剪区即可）。
- 颜色一律为 sRGB 浮点 `(r, g, b, alpha)`，渐变 stop 位置为 0–1 的半径比例。
- 背景透明，效果叠加在深色环境上最佳。

## 核心渲染原语（全部柔光只用这一招）

**环形 alpha 剖面的径向渐变，画在垂直压扁的坐标系里。**

1. 定义一个径向渐变：颜色 stop 的 alpha 剖面呈"环形"——中心透明 → 某半径处达到峰值 → 外缘归零。填充整个圆。
2. 需要椭圆时，不要生成椭圆路径：先对坐标系做 `scale(1, squash)`（以 C 为不动点），在压扁后的坐标系里画这个圆形渐变。
3. 结果是一条没有任何硬边的柔光椭圆环。**全场景禁止描边轮廓、禁止用路径边缘表现光**（三条盘面波纹是唯一的描边，且用粗软笔刷）。

伪代码：

```
drawSquashedRing(gradient, radius, squash, centerDx=0, centerDy=0):
    save()
    translate(C); scale(1, squash); translate(-C)
    # centerDy 是视觉偏移，压扁坐标系内要除回去
    drawRadialGradient(gradient, center=(C.x+centerDx, C.y+centerDy/squash),
                       from=0, to=radius)
    restore()
```

## 元素清单（7 个，含全部参数）

### 1. 环境辉光（最底层）
- 半径 `116 + 10·pull`，正圆。
- 渐变：`(1.00,0.40,0.10,0.07)@0 → (1.00,0.22,0.05,0.025)@0.55 → 同色 α0@1.0`

### 2. 吸积盘光带
- 半径 112，squash **0.27**（透视扁椭圆）。
- 渐变：`(1.00,0.90,0.66,0)@0→0.26 → (1.00,0.90,0.66,0.95)@0.33 → (1.00,0.66,0.20,0.80)@0.50 → (0.95,0.36,0.07,0.50)@0.75 → (0.85,0.20,0.04,0)@1.0`
- 内缘最热（乳白），向外递冷递暗到深红。

### 3. 盘面波纹环 ×3（唯一的每帧重建几何）
每环 28 个点构成闭合 Catmull-Rom 曲线（控制点 = 前后点差值 / 6），每帧重建：

```
amplitude = 0.05 + 0.08·pull
motion    = phase · speeds[i]            # speeds = (1.5, -1.2, 0.9) 层间反向
cycle     = (phase·0.12 + i/3) mod 1     # 该环的下落进度 0→1
radiusX   = 99 - (99-30)·cycle^1.6       # 加速下落（infall）
radiusY   = radiusX · 0.22
ripple(θ) = 0.6·sin(3θ + φ[i] + motion) + 0.4·sin(7θ - 0.6·motion + ψ[i])
             # φ = (0.3, 2.1, 4.4)  ψ = (1.7, 3.9, 0.8)
point(θ)  = C + (cosθ·radiusX, sinθ·radiusY) · (1 + amplitude·ripple(θ))
```

- 每环描边两层：宽 12 的柔光晕 + 宽 2.6 的亮芯，宽度均乘淡入淡出系数
  `fade = min(1, cycle·5, (1-cycle)·7)`；`fade < 0.05` 时跳过（**环必须在
  进入黑洞剪影前溶解完**）。
- 颜色（晕/芯）：环 0 `(1,0.80,0.45,0.10)/(1,0.88,0.60,0.38)`；
  环 1 `(1,0.70,0.32,0.09)/(1,0.78,0.45,0.34)`；
  环 2 `(1,0.55,0.20,0.08)/(1,0.62,0.28,0.30)`。圆头圆角连接。

### 4. 盘内缘火环（fire collar）
- 半径 `38 · (1 + 0.05·pull)`（与黑洞同增益同步呼吸），squash 0.27（躺在盘面里）。
- 渐变：`(0.98,0.45,0.10,0)@0→0.776 → (0.98,0.45,0.10,0.72)@0.853 → (1.00,0.62,0.20,0.52)@0.905 → (1.00,0.72,0.35,0.18)@0.953 → (1.00,0.60,0.25,0)@1.0`
- 它属于盘的一部分：远、近两个绘制层**都要画**（只画一侧会在赤道两侧产生硬接缝）。

### 5. 黑洞本体（事件视界）
- 半径 `33 · (1 + 0.05·pull)`，正圆。
- 渐变：纯黑 `α1.0 @ 0→0.91`，羽化到 `α0 @ 1.0`（即不透明到 30，羽化 30→33）。

### 6. 光子环火光（顶部）
- 半径 `46 · (1 + 0.05·pull)`，正圆，**裁剪到 y ≥ −10 区域**。
- 渐变：`(0.98,0.45,0.10,0)@0→0.615 → (0.98,0.45,0.10,1.0)@0.68 → (1.00,0.62,0.20,0.95)@0.74 → (1.00,0.85,0.55,0.85)@0.795 → (1.00,0.68,0.28,0.45)@0.87 → (1.00,0.55,0.20,0)@1.0`
- **黑核直接烧进亮橙**：黑与亮光之间禁止任何不透明的暗色 stop（会像画上去的轮廓线 / 第二个球壳）。

### 7. 弯曲光晕（上穹顶 + 下大晕）
**上穹顶**：半径 44·gain·脉动，squash `0.95·(1 + 0.03·sin(0.83·phase + 0.5))`，裁剪 y ≥ −10。
- 渐变：`(1,0.84,0.52,0)@0→0.79 → (1,0.86,0.55,0.90)@0.88 → (1,0.65,0.28,0)@1.0`
- 脉动（水面式，静息也动）：`radius ×= 1 + 0.03·sin(0.9·phase) + 0.022·sin(0.37·phase + 1.7)`
- 横向漂移：`centerDx = 1.5·sin(0.4·phase)`；`gain = 1 + 0.06·pull`

**下大晕**：半径 82·gain，squash 0.95，裁剪 y ≤ −10。
- 渐变：`(1,0.66,0.28,0)@0→0.65 → (1,0.68,0.30,0.30)@0.74 → (1,0.55,0.20,0)@1.0`
- **只颤动、不胀缩**（半径无脉动项），全部幅度乘 pull（安静时静止）：
  - squash `×= 1 + 0.06·pull·sin(2.9·phase + 1.9)`
  - `centerDx = 3.5·pull·sin(3.7·phase + 0.7)`
  - `centerDy = 2.8·pull·sin(5.3·phase + 2.6)`
  - 三个频率互质 → 颤动永不重复，像水面波纹。

## 绘制顺序（画家算法，关键！）

盘"从黑洞前面穿过"的立体感全靠远/近两个半区，所有交叠都是渐变叠渐变，无切割线：

```
1. 环境辉光（全画布）
2. 重建 3 条波纹环路径
3. 裁剪 y ≥ 0：   画盘（光带 + 3 环描边 + 火环）  ← 远半，被黑洞遮挡的一侧
4. 黑洞本体（全圆，无裁剪）
5. 裁剪 y ≥ −10： 光子环火光
6. 裁剪 y ≥ −10： 上穹顶
7. 裁剪 y ≤ −10： 下大晕
8. 裁剪 y ≤ 0：   再画一遍盘（同 3）          ← 近半，从黑洞前面穿过
```

裁剪线的选位不是随意的：**每条裁剪线都必须落在饱和亮光区**（赤道 ±10 是盘
最亮的地方），否则接缝立刻可见。每个裁剪块用图形状态栈包裹（save/restore），
异常路径也要恢复。

## 动画模型

- 单一 30Hz 定时器驱动（挂到不被 UI 滚动阻塞的 runloop 模式）。
- **累积相位**（禁止 `ω·t`，变速时会跳变）：
  ```
  dt = clamp(now - last, 0, 0.1)
  phase += 1.6 · (1 + 1.5·pull) · dt     # 静息 1.6 rad/s，说话最快 2.5×
  ```
- 所有运动（infall、波纹、脉动、颤动）共享这一个 phase → 声音让整个系统一起加速。
- 每次会话开始时 phase 归零。
- 入场动画：0.22s ease-out，scale 0.86→1.0 + 淡入；退场：0.20s ease-in，
  scale→0.76 + 淡出。**用合成器层动画（CA/Animator/CSS transform），
  不要在绘制循环里做**。

## 音频响应管线（持续说话必须持续波动）

```
麦克风 RMS（每 50ms 采样）
  → level = clamp(rms / REF, 0, 1)       # REF 取"正常说话 ≈ 0.6"的值
                                          # （16-bit PCM 下我们用 2400）
  → 调制检测：mean += (level - mean)·0.12          # ~1s 窗口的局部均值
              swing = min(1, |level - mean| · 3.5)
  → 不对称 EMA：swing 上升用 α=0.7（快攻），下降用 α=0.25（缓释）
  → smoothed = α·swing + (1-α)·smoothed
  → pull = smoothstep(clamp((smoothed - 0.22) / (0.55 - 0.22)))
           # smoothstep(x) = x²(3-2x)
```

**为什么用调制而不是音量**：语音在音节层面天然起伏，|level−局部均值| 对
连续说话永远非零 → 波纹一直动；而任何稳定信号（安静、风扇、恒定音乐）
均值会追上来 → swing 归零 → 画面回稳。直接用音量的话，说话几秒后 EMA
饱和，波纹就"死"了——这是实测踩过的坑。

`pull` 的驱动表：光流速度 ×(1+1.5·pull)、波纹深度 0.05+0.08·pull、
黑洞/光子环/火环半径 ×(1+0.05·pull)、穹顶/下晕半径 ×(1+0.06·pull)、
辉光半径 +10·pull、下晕颤动幅度 ×pull。

录音刚启动时用 0.3s 的 ease 把首个电平"接"进响应带，避免第一声突跳。

## 几何不变式（写成断言/单元测试，改参数必跑）

黑洞不透明核 = 30，羽化边 = 33（说话时整体 ×1.05）：

1. 上穹顶空心最坏情况必须包住黑核：
   `44·0.79·(1−0.03−0.022)·0.95·(1−0.03) ≥ 30`
2. 下大晕空心颤到极限也必须包住黑核：
   `82·0.65 − 3.5 ≥ 30` 且 `82·0.65·0.95·(1−0.06) − 2.8 ≥ 30`
3. 火环最亮圈可骑在羽化带上，但不得进入不透明核：`38·0.853 ≥ 30`
4. 光晕的声音增益 ≥ 黑洞的声音增益（0.06 ≥ 0.05），大声说话不会破坏包裹。
5. 波纹环在 `fade < 0.05` 前必须消失，且最内半径 30 不小于黑核。
6. 所有元素（含最大描边半宽、最大脉动/颤动）留在画布内 ≥ 1pt 边距。

**尺寸用不等式算出来，不要目测**——这是整个开发过程中最重要的方法论。

## 性能预算（钉进测试）

- 每帧：9 次渐变绘制（辉光 1 + 光带 2 + 火环 2 + 黑洞 1 + 光子环 1 + 穹顶/下晕 2）、
  12 次描边（3 环 × 2 层 × 2 遍）、84 段曲线重建（3 × 28）。
- 颜色、渐变、路径对象全部启动时创建一次并缓存；绘制循环内**零分配**
  （缓存要么全建好要么全没有，失败可干净重试）。
- 静止与说话成本恒定。

## 实施步骤（按序，每步自检）

1. 搭画布 + 30Hz 循环 + 累积相位；先画黑洞本体和环境辉光。
2. 加吸积盘光带（学会核心原语：压扁坐标系里的环形渐变）。
3. 实现远/近两半绘制顺序，确认盘从黑洞前面穿过且无接缝。
4. 加 3 条波纹环 + infall 循环 + 淡入淡出。
5. 加光子环火光（上）+ 火环（盘内缘），检查黑核边缘无暗线。
6. 加两个光晕 + 静息呼吸 + 下晕颤动。
7. 接音频管线，验证：持续说话持续波动、停顿回稳、稳态噪声不触发。
8. 写几何不变式断言 + 性能预算断言。
9. 入退场动画。

**每一步都把画面渲染成图片、放大自查**（离屏渲染 → 导出 PNG →
以 2–5 倍放大检查接缝/暗线/穿帮），不要盲画。这是本效果打磨的核心流程。

## 踩坑清单（真实迭代教训，每条都返工过）

1. **黑核与亮光之间放了不透明暗红过渡** → 看起来像用笔画的轮廓线/套了第二个球壳。修法：火色直接接黑。
2. **半透明白色叠在暗背景上会"洗灰"** → 灰脏弧线。高光要么加饱和度要么提 alpha（我们用 α0.85 的金黄替代 α0.62 的乳白）。
3. **只在一个半区画的元素，裁剪线必须落在饱和亮区**，否则赤道处出现亮度断层；属于盘的元素（火环）远近两遍都画。
4. **用 `ω·t` 算相位** → 音量变化瞬间纹理跳变。必须累积 `phase += speed·dt`。
5. **用音量直接驱动波纹** → 连续说话几秒后画面"死"。必须用调制检测（|level−局部均值|）。
6. **光晕空心目测调整** → 反复穿帮。写成最坏情况不等式一次解决。
7. **波纹环不淡出** → 被吞进黑洞时在剪影上残留一段亮线。
8. **光晕左右摆动幅度过大** → 与黑洞脱开穿帮。漂移 ≤ 1.5pt。
9. **"呼吸"做成整体缩放** → 机械感。要么是光流动（相位加速），要么是多频率互质的形状微颤。
10. **入退场动画放进绘制循环** → 卡顿。交给合成器（layer transform）。

## 平台适配提示

- **HTML**：Canvas 2D `createRadialGradient` + `ctx.scale` + `ctx.clip`；入退场用 CSS transform/opacity；音频用 WebAudio AnalyserNode 取 RMS。
- **macOS/iOS**：NSGradient/CGGradient + CGAffineTransform + `CGContextClipToRect`；入退场用 Core Animation；注意把动画值包成平台对象（如 NSValue）。
- **Android**：Canvas + RadialGradient（SRC_OVER 正常混合）+ `canvas.scale/clipRect`；入退场用 ViewPropertyAnimator / Compose animate。
- **Windows**：Direct2D RadialGradientBrush 或 Skia；合成动画交给 Composition API。
- 所有平台：渐变 stop 的插值行为略有差异，若某段过渡发闷，微调相邻 stop 的位置（±0.02）而不是改颜色。
